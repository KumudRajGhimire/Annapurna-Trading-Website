# Annapurna Trading Pvt. Ltd. – Official Website

This repository contains the source code for the official website of **Annapurna Trading Pvt. Ltd.**

The website serves as the company's digital presence, providing visitors with information about the business, its services, and other relevant company details.

## Tech Stack

- **Frontend:** JavaScript / React
- **Package Manager:** npm
- **Development Server:** Vite (if applicable)

## Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm (comes bundled with Node.js)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-directory>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

### Run Locally

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL displayed in your terminal.

To access it from another device on the same network, use your machine's local IP address and the port displayed by the development server.
